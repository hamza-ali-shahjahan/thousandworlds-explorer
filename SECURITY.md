# Security Policy

ThousandWorlds is a fully static, client-side web app. It has no backend, no
database, no user accounts, and stores no secrets — it just renders a public
NASA dataset in the browser. The attack surface is therefore very small.

If you do find a security concern (for example in a dependency), please report it
privately by opening a [GitHub Security Advisory](https://github.com/hamza-ali-shahjahan/thousandworlds-explorer/security/advisories/new)
rather than a public issue, and we'll address it promptly.
